- Two automated test scripts drove real Firebase-authenticated requests against the running server and asserted on the actual response: 34 checks against plan limits/features, 21 checks against the Stripe payment lifecycle.
- Both scripts were run **twice** — once initially, and again after three bugs found during manual review (below) were fixed — to confirm the fixes didn't break anything already verified. Both runs passed 55/55.

## 5. Bugs found and fixed during manual review (not part of the 55 — found by using the product directly)

These weren't caught by the automated checks above because they're rendering/formatting issues, not access-control issues. Found by actually using the site in a browser, fixed immediately, then the full 55-check suite was re-run to confirm nothing broke.

1. **Decision Playbook could occasionally render blank for a paying customer.** In one live run, the AI's phrasing left the "final recommendation" field technically empty, which hid the entire paid section. Fixed by deriving a sensible fallback from the rest of the report, so this section can no longer disappear.
2. **Pricing page overflowed off-screen on phones.** A leftover CSS rule further down the stylesheet was silently overriding the mobile layout rule, pushing the plan cards ~12px past the edge of the screen. Fixed.
3. **Account/profile page also overflowed on phones**, for a similar reason (a 4-item stat row that didn't wrap on narrow screens). Fixed.

## 8. What this confirms

- A customer only ever gets what their plan pays for — enforced by the server, not the browser, so it can't be bypassed by editing requests or the page.
- Upgrades activate correctly even if the checkout tab is closed before the confirmation screen loads.
- A cancelled or expired subscription loses paid access immediately, not after some delay.
- The plan someone is granted always comes from what Stripe says they paid for — never from anything the browser claims.

No customer data or real payments were involved in any of the above — the test account and all Stripe test objects created during this run have been deleted.
